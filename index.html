About these formats ▸

Household List

One row per household: Household Name, People (semicolon-separated), Full Address. Same format as the original Python script.

Mail Merge / Labels

One row per household with address split into columns for Word/Google Docs mail merge or label printing: Family Name, Street 1, Street 2, City, State, Zip.

Per-Person List

One row per individual: First Name, Last Name, Household, Email, Phone, Street 1, Street 2, City, State, Zip. Useful for sites that need individual entries.

Zola / The Knot

One row per person grouped by household/party: First Name, Last Name, Party Name, Email, Phone, Address, City, State, Zip, Country. Import into Zola or The Knot guest lists.

How to export from Planning Center

  1. In Planning Center, open the People module
  2. Apply any filters you'd like (e.g., by campus or group), or leave blank for everyone
  3. Click Export (top right) → Export as CSV
  4. Make sure to include: First Name, Middle Name, Last Name, Household ID, Household Name, Membership, and all Home Address fields
  5. Upload the downloaded .csv file above
Your data never leaves your browser. No server, no upload, no account needed.
